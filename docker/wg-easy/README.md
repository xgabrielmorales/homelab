# VPN + DNS

- [WireGuard Easy](https://github.com/wg-easy/wg-easy) It's a wrapper around WireGuard, adding features like a Web UI, client administration, and many other features.
- [Pi-hole](https://github.com/pi-hole/pi-hole) is a network-wide ad blocker.
- [Unbound](https://github.com/NLnetLabs/unbound) is a validating, recursive, caching DNS resolver.
